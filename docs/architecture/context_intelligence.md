# Context Intelligence & Planning Engine

The Context Intelligence Engine (Layer 3.2) is the semantic optimization layer of the Brain. It takes the raw Context Plan generated by the Decision Engine and processes it into a highly efficient, contradiction-free `ContextPack`.

## Pipeline
1. **Graph Building**: Assembles a `ContextGraph` of required, useful, and optional features and symbols.
2. **Policy Application**: Modifies relevance scores based on Task Intent (e.g., Bug Fixes prioritize Tests, Features prioritize Architecture).
3. **Freshness Analysis**: Uses L2.7 Evolution APIs to slightly boost the relevance of symbols that were modified recently.
4. **Diversity Check**: Penalizes the relevance score of highly redundant symbols (e.g., 50 symbols from the same utility file) to ensure the AI gets a broad view of the architecture.
5. **Semantic Compression**: Iteratively squashes low-priority items from `FULL` to `SUMMARY` to `METADATA` representations to forcefully pack them into the token budget without losing their existence entirely.
6. **Contradiction Detection**: Sweeps the final graph for broken architectural constraints.
