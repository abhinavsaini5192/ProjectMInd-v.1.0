# Evolution Metrics

The `EvolutionMetrics` module analyzes timelines to compute historical trends:
- **Change Frequency**: How often is the repository updated?
- **Hotspots**: Which symbols or features are modified most frequently? (High churn risk).
- **Technical Debt Trend**: Is the overall Architecture Violation count going up or down over the last month?
- **Stability Trend**: Are core features stabilizing or continually thrashing?
