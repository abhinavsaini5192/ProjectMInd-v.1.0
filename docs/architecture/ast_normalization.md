# AST Normalization Architecture

The `ASTNormalizer` walks the raw tree generated by the `ParserFramework` and translates structural constructs.

## The Language Mapper
Translations are defined deterministically in the `LanguageMappingRules` dictionary. 
For example, a Java `marker_annotation` and a Python `decorator` both translate to `NodeKind.Decorator`.

## Edge Cases
Some translation requires context. For example, a Python `function_definition` might map to `NodeKind.Function` if its parent is a Module, but map to `NodeKind.Method` if its parent is a Class. The Normalizer resolves these.
