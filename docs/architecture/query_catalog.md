# Query Catalog

The engine exposes 8 distinct API handlers, corresponding to the entities within ProjectMind:

1. **Repository**: Stats, Health, Languages.
2. **Symbols**: Find, Dependents, History.
3. **Features**: Find, Dependencies, Routes.
4. **Relationships**: Callers, Implementations, Exports.
5. **Dependencies**: Circular, Critical, Chain.
6. **Architecture**: Violations, Coupling, Layers.
7. **Evolution**: History, Hotspots, Churn.
8. **Impact**: Blast Radius, Risk Score.
