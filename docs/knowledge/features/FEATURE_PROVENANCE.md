# Feature Provenance & Evidence

ProjectMind explicitly records how each feature was established and calibrated.

## Feature Origins
- `MANUAL`: Explicitly defined by human engineers.
- `DISCOVERED`: Discovered automatically via algorithmic structural scanning.
- `IMPORTED`: Ingested from external specifications or PRDs.
- `INFERRED`: Derived from dependency clusters and heuristic evidence.

## Evidence Tracking
`FeatureEvidence` links features to the precise AST symbols, API routes, and commit events that justify its existence and confidence score.
