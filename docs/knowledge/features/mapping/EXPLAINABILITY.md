# Mapping Explainability & Auditing

## Principles of Explainability

An AI architecture intelligence platform must never operate as an inscrutable black box. Every mapping decision made in Phase 6.3 must answer three questions:

1. **Why is this resource mapped to this feature?**
2. **What evidence supports the assigned role and confidence score?**
3. **Were there any conflicts or competing assignments?**

---

## The `MappingExplanation` Contract

Generated by `FeatureMappingExplainer`:

```typescript
export interface MappingExplanation {
  mappingId: string;
  featureId: string;
  resourceId: string;
  resourceType: string;
  role: string;
  confidence: {
    level: string;
    score: number;
    reasons: string[];
  };
  score: number;
  source: string;
  evidenceCount: number;
  evidenceSummary: string[];
  conflicts: MappingConflict[];
  knowledgeVersion: string;
  mappingVersion: number;
  active: boolean;
  reasoningSummary: string;
}
```

---

## Human-Readable Reasoning Without Scratchpad Leaks

The explainer synthesizes a concise, structured `reasoningSummary` that cites the exact evidence signals:

```json
{
  "mappingId": "map_auth_svc_102",
  "featureId": "feat_auth",
  "resourceId": "src/auth/AuthService.ts",
  "role": "IMPLEMENTATION",
  "confidence": {
    "level": "VERY_HIGH",
    "score": 0.95,
    "reasons": [
      "Symbols contributed 0.20",
      "Test suites contributed 0.15",
      "Cross-source diversity bonus (+0.10) from 2 distinct sources"
    ]
  },
  "evidenceCount": 2,
  "evidenceSummary": [
    "Symbol \"AuthService\" (ClassDeclaration) in src/auth/AuthService.ts: Inferred capability \"Authentication\" exactly matches feature name \"Authentication\"",
    "Test suite \"Authentication Service Suite\" verifies behavior of feature \"Authentication\""
  ],
  "reasoningSummary": "Resource \"src/auth/AuthService.ts\" is mapped to feature \"feat_auth\" as IMPLEMENTATION based on 2 evidence signals (Symbol \"AuthService\" (ClassDeclaration) in src/auth/AuthService.ts: Inferred capability \"Authentication\" exactly matches feature name \"Authentication\"). Confidence: VERY_HIGH (0.95)."
}
```

**Guardrails**: Internal LLM thinking tags (`<thought>`, `assistant:`, reasoning chain traces) are strictly excluded from explanation payloads.
