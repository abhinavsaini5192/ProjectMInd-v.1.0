# Semantic Feature Relationships

`FeatureRelationship` captures semantic interconnections between features.

## Relationship Types
- `DEPENDS_ON`: Functional requirement on another feature.
- `CONTAINS`: Sub-feature or compositional hierarchy.
- `EXTENDS`: Augmentation of existing capabilities.
- `SUPPORTS`: Ancillary or enablement role.
- `INTEGRATES_WITH`: Inter-service or inter-feature data exchange.
- `CONFLICTS_WITH`: Incompatible feature configurations.
- `REQUIRES`: Mandatory prerequisite.
- `RELATED_TO`: Associative connection.
