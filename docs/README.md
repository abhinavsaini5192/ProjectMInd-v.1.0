# ProjectMind Documentation Portal

Welcome to ProjectMind, the universal repository operating system for AI coding assistants.

## Getting Started
- **Installation**: Run `npm i -g projectmind` or use our Docker image.
- **Initialization**: Run `projectmind init` in your repository root.
- **Diagnostics**: Run `projectmind doctor` if you encounter any issues.
