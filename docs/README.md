## 📁 Directory Structure

* **`architecture/`**: High-level designs and architectural decisions.
* **`specifications/`**: Rigid technical contracts (e.g., memory and graph specs).
* **`development/`**: Guidelines for contributing and AI workflows.
* **`guides/`**: Tutorials, migration guides, and deployment configurations.
* **`generated/`**: References that will be automated in CI/CD pipelines.
* **`adr/`**: Architecture Decision Records (Historical design logs).
